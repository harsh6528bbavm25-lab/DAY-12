## 📖 Project Description
This project explores how **Generative AI can support airport passenger-service teams** in activities such as drafting passenger communications, summarising feedback, preparing FAQs, and organising information.

The project follows a **human-in-the-loop approach**, where AI assists with creating drafts but employees verify the information before approval and communication.

## 🎯 Objectives
- Understand the use of Generative AI in airport passenger services.
- Identify practical AI use cases in aviation.
- Demonstrate an AI-assisted passenger communication workflow.
- Identify risks such as hallucinations, outdated information and privacy issues.
- Apply human review and governance principles.
- Create a professional aviation-focused presentation.

## 🔄 AI Workflow

**Verified Information → Structured Prompt → AI Draft → Human Review → Approval → Passenger Communication**

The workflow ensures that AI-generated content is checked for accuracy and suitability before being used.
